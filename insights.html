What is Quantum Machine Learning?

Quantum Machine Learning asks whether quantum circuits can represent or speed up parts of a learning pipeline. Most useful work today is hybrid. AlgoLex studies that intersection as a PhD programme. It is early science, not a consumer app.

What an AI agent can do

An agent is a loop: take an input, decide, call a tool, return an output. Good agents are narrow. AlgoLex designs agents only after the workflow is written down.
